# Visit Japan Web (online arrival procedures)

## What it is

Visit Japan Web is an official web service from Japan's Digital Agency. You use it to do arrival procedures online: **immigration clearance and the customs declaration**. Foreign visitors can also use it for tax-free shopping during their stay.

## How it works

- Register the information needed for immigration procedures in advance.
- At the airport you show a **2D code**. Since January 2024, one unified code is used for both immigration and customs.
- You can register on a PC, but you need a smartphone or tablet to present the 2D code at arrival.

## Cautions from the page

- Suspicious look-alike apps (for example one called "Visit Japan Web Info") have been reported. Use the official site.
- The page lists official FAQs for quarantine, immigration, customs, and animal and plant quarantine. Inquiries go through the site's chatbot.
